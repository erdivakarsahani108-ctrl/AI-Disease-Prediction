# Contact / Feedback

This is an academic (Final Year B.Tech) Data Science + AI project.

## For questions about this repository

Please use your repository host's issue tracker (e.g. GitHub Issues) on
this project's repository to:
- Report a bug
- Suggest a feature (see `docs/limitations.md` for known Future Scope
  items already identified)
- Ask a question about the methodology

## In-app feedback

Every prediction in the **AI Health Assistant** and **Disease Prediction**
pages includes 👍 / 👎 feedback buttons. This feedback is stored
anonymously (see `docs/privacy_policy.md`) purely for qualitative review
by the project maintainer - it does not automatically change model
behavior.

## No medical support is provided through this channel

This contact channel is for **software/project feedback only**. It is
not a medical helpline. If you have a health concern, please contact a
qualified healthcare professional or your local emergency services (see
`docs/medical_disclaimer.md`).
